# QQ 机器人官方文档（整理版）

来源：[bot.q.qq.com 开发文档](https://bot.q.qq.com/wiki/develop/api-v2/)（markitdown 抓取，散页已按业务域归类整理）。
整理范围：接入准备、OpenAPI 接口、事件、频道域功能，以及面向 mock 开发的速查附录。

## Mock 开发阅读路线

1. **鉴权**：[获取访问凭证](01-接入准备/获取访问凭证.md)（AppID/AppSecret 换 access_token）→ [API调用指南](01-接入准备/API调用指南.md)（Authorization 头、响应结构、公共错误码）
2. **事件通道二选一**：[Webhook回调方式](01-接入准备/Webhook回调方式.md)（含 ed25519 签名校验）或 [WebSocket网关方式](01-接入准备/WebSocket网关方式.md)（Identify/心跳/Resume）
3. **事件结构**：[事件订阅通用数据结构](01-接入准备/事件订阅通用数据结构.md)（payload / OpCode / Intents）
4. **消息收发**：[02-API接口](02-API接口/)（群聊/单聊）与 [03-事件](03-事件/)（对应推送事件体）
5. **速查**：[接口清单总表](05-速查附录/接口清单总表.md) · [事件与Intents对照表](05-速查附录/事件与Intents对照表.md) · [错误码汇总](05-速查附录/错误码汇总.md)
